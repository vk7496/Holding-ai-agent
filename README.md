# Holding-ai-agent
# سامانه جامع ایجنت هوشمند هلدینگ (Unified Holding AI Agent)

پلتفرم یکپارچه مبتنی بر هوش مصنوعی برای اتوماسیون فرآیندهای منابع انسانی (HR)، مدیریت اداری و خدمات داخلی هلدینگ بدون دخالت انسان.

## 🚀 ویژگی‌های کلیدی
- **ماژول استخدام و جذب (HR Sub-Agent):** تحلیل و غربالگری خودکار رزومه، تطبیق با ماتریکس شایستگی و تولید سوالات مصاحبه.
- **دستیار اداری (Admin Sub-Agent):** پاسخگویی هوشمند به آیین‌نامه‌ها و ثبت خودکار درخواست‌های پرسنلی (وام، مرخصی و...).
- **معماری مقیاس‌پذیر:** قابلیت اتصال به سیستم‌های مالی و منابع انسانی سازمانی.
